# Hi, I'm Zahra Jafari 👋

I'm a master's student in Robotics and Autonomous Systems at the University of Lübeck. I build practical AI applications with Python, machine learning, retrieval systems, and LLMs.

## Selected projects

- **[Partner–topic matching pipeline](https://github.com/Mahlaj94/partner-topic-matching)** — A pipeline that crawls public pages, combines dense and BM25 retrieval, and uses an LLM to assess topic relevance with source evidence.
- **[IMDb sentiment analysis with MLflow](https://github.com/Mahlaj94/imdb-sentiment-mlflow)** — Compares text classifiers, tracks experiments with MLflow, selects a model by F1 score, and serves predictions through a Flask API.
- **[AI Email Assistant](https://github.com/Mahlaj94/ai-email-assistant)** — A Google Apps Script demo that classifies selected Gmail messages with Gemini, prepares editable reply drafts, and alerts me on WhatsApp for urgent messages.
